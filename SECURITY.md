# Security Policy

## Reporting a Vulnerability

As an aspiring cybersecurity professional, security and responsible disclosure are taken very seriously.

If you believe you have found a security vulnerability in this portfolio website or any affiliated project, please report it responsibly.

### How to Report

- **Email**: Send vulnerability reports directly to [sukesh.me@gmail.com](mailto:sukesh.me@gmail.com)
- **Subject**: `[SECURITY VULNERABILITY] <Brief Description>`
- Please include:
  - Step-by-step instructions to reproduce the issue
  - Proof of concept (where safe and applicable)
  - Potential impact assessment
  - Any relevant HTTP headers or configurations

### Disclosure Guidelines

- Do not publicly disclose the vulnerability until it has been acknowledged, addressed, and resolved.
- Please do not attempt denial of service, destructive attacks, or extraction of unauthorized data.
- Reports will be reviewed promptly.

Thank you for contributing to keeping software safer!
